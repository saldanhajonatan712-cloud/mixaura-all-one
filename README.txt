MIX AURA ALL-IN-ONE — VST3 para Windows x64

REQUISITO DO WINDOWS
O plugin utiliza o runtime Microsoft Visual C++ 2015–2022 x64. Se ele nao
estiver instalado no Windows, instale o redistribuivel oficial:
https://aka.ms/vs/17/release/vc_redist.x64.exe

INSTALACAO NO FL STUDIO
1. Extraia o arquivo ZIP.
2. Copie a pasta "MIX AURA ALL-IN-ONE.vst3" para:
   C:\Program Files\Common Files\VST3\
3. No FL Studio, abra Options > Manage plugins.
4. Selecione Find installed plugins.
5. Carregue "MIX AURA ALL-IN-ONE" em um slot do Mixer.

O pacote inclui o bundle VST3 compilado para Windows x64 e estas instrucoes.
O plugin requer um host compatível com VST3 de 64 bits.
